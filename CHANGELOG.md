# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/) and the structure recommended by [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- Segment-based reserved-seat availability and booking.
- PostgreSQL exclusion constraint for concurrent overlap protection.
- Fare quotes, booking lookup, cancellation, and audit events.
- Responsive multilingual passenger web application and seat map.
- Docker Compose development workflow, CI, and repository governance.

### Security

- Strict JSON decoding, parameterized SQL, configured-origin CORS, security headers, and idempotent booking creation.
