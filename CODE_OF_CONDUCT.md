# Code of Conduct

## Our standards

We are committed to a respectful, inclusive, and harassment-free community. Contributors must communicate constructively, respect differing experience and viewpoints, accept feedback professionally, and prioritize passenger safety, privacy, and system correctness.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, publishing private information, deliberate disruption, and using project spaces for unrelated promotion.

## Enforcement

Project maintainers may edit, remove, or reject contributions and temporarily or permanently restrict participation when behavior violates these standards. Enforcement decisions should be proportional, documented privately, and focused on protecting the community.

Report conduct concerns privately through the repository security contact described in `.github/SECURITY.md`. Do not open a public issue containing personal or sensitive information. Maintainers will acknowledge reports, review them impartially, and protect reporter privacy where possible.

## Scope

This policy applies in repository discussions, issues, pull requests, reviews, community spaces, and when representing the project publicly.
